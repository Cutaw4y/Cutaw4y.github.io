Privacy Policy

Last updated: 29 October 2026

OtoYT ("the app") is a private, single-user tool operated by the owner of the Cutaway YouTube channel. It is used only to publish the channel owner's own videos and to read the channel's own statistics. It is not offered to the public and has no other users.

What data the app accesses

  • YouTube upload access (youtube.upload, youtube): to upload videos and thumbnails to the owner's own Cutaway channel and set their title, description and privacy.
  • YouTube Analytics read access (yt-analytics.readonly): to read view counts and average view percentage of the channel's own videos, so the owner can see which topics perform best.

How the data is used and stored

  • Data is used only for the purposes above.
  • The only data stored is a list of the channel's own published video titles, video IDs and dates, kept in the owner's private repository.
  • OAuth credentials are stored as encrypted secrets in the owner's private GitHub repository.
  • No data is sold, shared with, or transferred to third parties, and none is used for advertising.
  • No data about any other YouTube user or viewer is collected.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; by using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted on request.

Contact

Questions about this policy can be sent through the contact details on the Cutaway YouTube channel's About page.
