Privacy Policy

Last updated: 30 October 2026

OtoYT ("the app") is a private, single-user publishing tool operated by one individual, the owner of the YouTube channels Cutaway (English, science and engineering) and Gölgedefter (Turkish, history and mysteries). Both channels belong to the same Google account. The app is used only to publish the owner's own original videos to these two channels and to manage and measure them. It is not offered to the public and has no other users.

What data the app accesses

  • YouTube upload and management access (youtube.upload, youtube, youtube.force-ssl): to upload the owner's own videos and thumbnails, set their title, description, tags, privacy and scheduled publish time, upload caption (subtitle) files, add videos to the channel's own playlists, set the channel's own banner and description, and post one comment from the channel on its own videos.
  • Public comments on the channel's own videos (youtube.force-ssl, read only): the text of recent public comments is read so the owner can see which topics viewers ask for. Comment text is used only at that moment, is never stored, and no commenter names or profile data are kept.
  • YouTube Analytics read access (yt-analytics.readonly): view counts and average view percentage of the channel's own videos, used to decide which topics to make next.

How the data is used and stored

  • Data is used only for the purposes above, for the owner's own channels.
  • Stored data is limited to the channels' own published video titles, video IDs, publish dates and playlist IDs, kept in the owner's private repository. No viewer data is stored.
  • To generate scripts and topic ideas, the channel's own video titles, aggregate statistics and the temporary comment text described above are processed by Google's Gemini API. No other third party receives YouTube data.
  • OAuth credentials are stored as encrypted secrets in the owner's private GitHub repository.
  • No data is sold, shared for advertising, or transferred to anyone else.
  • Analytics values are refreshed from the API and are not kept for more than 30 days.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; by using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. Stored data can be deleted on request by email.
